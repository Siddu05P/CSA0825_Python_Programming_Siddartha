Each folder contains the program (`*.py`), the output produced when it was run (`output_*.txt`) and a `screenshots/` folder for your own screenshots of the program and its output.

Task 5: each of `a`, `b`, `c`, `d` runs with `python attendance_app.py` (a) or `python main.py` (b, c, d) from inside that folder.
